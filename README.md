# Lokalo POS downloads

Installer files for Lokalo POS. Application source is maintained privately.

TEST installers are unsigned development packages for a clean, disposable Windows 11 x64 computer or virtual machine. They are not approved for live tills.

Download channels: https://lokalo-vendor-dev.onrender.com/customer/downloads/windows

Verify the installer SHA-256 against the checksum attached to its release before running it. Installation requires administrator access; activation requires a separate installation-specific license from the development vendor.
